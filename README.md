# ARL

ARL is a private Constitutional Law MBE mechanics pilot.

The core question is:

```text
What is the smallest mechanical note that lets a smart non-lawyer reject this trap and pick the right answer next time?
```

V0 builds the scoring and mutation loop around a mutable mechanics pack:

- `study/mechanics_pack.yaml`
- `study/tiny_anchors.yaml`
- `study/subject_overlays/constitutional_law.yaml`
- `study/exam_day_scripts/conlaw_script.md`

Private books, questions, answer keys, explanations, attempts, and run outputs stay out of Git under `data/private/` and `runs/`.
