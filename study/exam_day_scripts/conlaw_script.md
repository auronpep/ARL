# Constitutional Law Exam Script

1. Name the actor first.
2. If federal, find the enumerated power or spending/commerce hook.
3. If state, find the constitutional limit, classification, right, burden, or threshold.
4. If the law divides people into groups, route to Equal Protection style analysis, then check actor.
5. Run threshold before merits: state action, standing, property interest, permit discretion.
6. Cut wrong-actor clauses and high-frequency bait.
7. If two answers survive, name the clash axis and use the dispositive fact.

Student mantra: Claim home first. Burden follows tier. Threshold beats merits.
